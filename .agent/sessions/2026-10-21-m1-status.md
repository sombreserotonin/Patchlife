# 2026-10-21 M1 start: status computation

M0 merged with CI green, so M1 started on `claude/m1-status`.

- Opened #9 (create the `crawl` environment now, not in M3) and #10 (choose the crawler contact URL now, not at launch). Without both, `verify:evidence` cannot fetch, so no record can reach `verified`.
- Added `computeStatus(record, today)`: `unknown` without an end date, `ended` after it, `ending_soon` up to one year out, else `supported`. It relies on the validator's guarantee that `end_date` is set only from a published date or anchor. Display wording for relative rules ("3 years after Acme ends sales ...") is left for the M2 site.

Next: the verifier core with offline fixtures (HTML to text, normalise, match, hash), then a separate protected PR for the `verify:evidence` script and any PDF dependency.
