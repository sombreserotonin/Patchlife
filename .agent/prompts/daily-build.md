1. Re-verification (RUNBOOKS A9): the `Re-verify evidence` workflow pushes `claude/reverify-<date>` branches and opens no PR. Otherwise label it `needs-human` with a comment. If the newest successful run of `reverify.yml` (`gh api "repos/sombreserotonin/Patchlife/actions/workflows/reverify.yml/runs?status=success&per_page=1"`) finished more than 48 hours ago, say so in the final status line.

Then repair at most one failing or conflicted agent PR that is not labelled `needs-human` (RUNBOOKS A7). After two failed repairs of the same PR, label it `needs-human`, comment why, and stop touching it.
