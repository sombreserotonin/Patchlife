## Confirmed defects

### F3, `scripts/verify-evidence.mjs:231`, published status (High)
1. `doc.setIn(["verification", "status"], "stale")` ran whenever a verified record's quote was missing from the fetched text.
2. Data flow: `polite-fetch.mjs` returns any 200 body as the page, so a firewall's challenge page reached `verifyRecord`.
3. Controls: `check-source.mjs` had a `CHALLENGE` test, and the verifier had none. The change is verification-only, so the gate passes it and the merge bot merges it.

Scenario: one night TP-Link's host answers runners with a 200 "Just a moment..." page. Up to 664 correct records turn stale, and the next day the site shows them as "Under review".

Fix (#226): the phrases moved to `verify-evidence.mjs`, shared with `check-source.mjs`.
- A record that would turn stale on a page holding one of them is reported as `error` instead, which leaves the file unchanged.
- The wall's hash is not stored.
- A real page that only mentions a phrase still verifies when its quotes are there.

### F1, `scripts/polite-fetch.mjs:11`, availability
`ruleRegExp` turned each `*` into `.*`. Fix (#230): `ruleMatches` walks the rule, backtracking only to the last `*`. It agreed with the old expression on 200,000 random rule and path pairs.

### F5, `scripts/polite-fetch.mjs:131`, availability
`res.text()` and `res.arrayBuffer()` read whole bodies after decompression. Fix (#230): a streaming read stops past 32 MiB, robots.txt included, and the text is decoded with `TextDecoder`, as `res.text()` decodes UTF-8.

### F2: open; L1: fixed in #235
- **F2, `scripts/verify-evidence.mjs:53`:** each replacement in `htmlToText` can rescan to the end from every unclosed opener. It is left as it is. Its output decides every quote match and page hash, and the owner dismissed CodeQL's finding on it; any change must give the same text for every real page.
- **L1, `scripts/polite-fetch.mjs:71`:** the gap was read, then `lastRequest` set after an `await`. Fix (#235): requests to a host take turns, each waiting until the one before it is sent. Calls made one after another are spaced exactly as before.

## Refused or unconfirmed candidates
- C1, SSRF through a redirect: refused, lens existing mitigation.
  - A body counts only when `samePage` holds, and another origin fails it.
